# Evaluation Framework Guide

## Overview

This guide explains how to evaluate and compare three variants of the Llama-3.1-8B model:

1. **Baseline:** Llama-3.1-8B-Instruct (no additional training)
2. **Standard Self-Play:** Llama-3.1-8B after standard forward-only self-play
3. **Meta-Cognitive Self-Play:** Llama-3.1-8B after meta-cognitive self-play (our approach)

## Workflow

### Step 1: Download Benchmarks

```bash
bash scripts/download_benchmarks.sh
```

This downloads:
- GSM8k (grade school math)
- MATH (competition mathematics)
- MMLU (massive multitask language understanding)

### Step 2: Evaluate Baseline Model

```bash
python scripts/evaluate_baseline.py \
    --model meta-llama/Llama-3.1-8B-Instruct \
    --benchmarks gsm8k,math,mmlu \
    --output_dir data/results/baseline
```

### Step 3: Train Standard Self-Play Model

```bash
python scripts/train_standard_selfplay.py \
    --base_model meta-llama/Llama-3.1-8B-Instruct \
    --output_dir checkpoints/standard_selfplay \
    --num_iterations 50000
```

### Step 4: Evaluate Standard Self-Play

```bash
python scripts/evaluate_standard.py \
    --model checkpoints/standard_selfplay/final \
    --benchmarks gsm8k,math,mmlu \
    --output_dir data/results/standard_selfplay
```

### Step 5: Train Meta-Cognitive Self-Play Model

```bash
python scripts/train_teacher.py \
    --config config/teacher_config.yaml \
    --output_dir checkpoints/metacog_selfplay \
    --num_iterations 50000
```

### Step 6: Evaluate Meta-Cognitive Self-Play

```bash
python scripts/evaluate_metacog.py \
    --model checkpoints/metacog_selfplay/final \
    --benchmarks gsm8k,math,mmlu \
    --output_dir data/results/metacog_selfplay
```

### Step 7: Compare All Models

```bash
python scripts/compare_models.py \
    --result_dirs data/results/baseline,data/results/standard_selfplay,data/results/metacog_selfplay \
    --output_dir data/results/comparison
```

## Metrics Computed

For each benchmark, we compute:

1. **Accuracy:** Percentage of correct answers
2. **Exact Match:** Strict string matching
3. **Numerical Equivalence:** For math problems (e.g., "0.5" == "1/2")
4. **Per-Category Accuracy:** For MMLU (STEM, Humanities, Social Sciences, Other)
5. **Difficulty-Stratified Accuracy:** For MATH (Level 1-5)

## Quick Start

Run all evaluations in sequence:

```bash
# 1. Download benchmarks
bash scripts/download_benchmarks.sh

# 2. Evaluate all three models
bash scripts/run_all_evaluations.sh

# 3. Generate comparison report
python scripts/compare_models.py

# 4. View results
cat data/results/comparison/comparison_table.md
```

## Expected Timeline

- **Benchmark download:** 10-15 minutes
- **Baseline evaluation:** 2-3 hours (on 1× A100)
- **Standard self-play training:** 2-3 weeks
- **Standard self-play evaluation:** 2-3 hours
- **Meta-cognitive self-play training:** 2-3 weeks
- **Meta-cognitive evaluation:** 2-3 hours
- **Comparison report generation:** 1 minute

## Notes

- All evaluations use the same random seed for reproducibility
- Results are cached to avoid re-running expensive evaluations
- Use `--force` flag to override cached results
- GPU memory: ~40GB for Llama-3.1-8B inference
- Batch size: 8 (adjustable based on available GPU memory)
